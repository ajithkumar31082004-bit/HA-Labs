# HA Labs — Engineering Projects. Built for Reality.

> **Find it. Build it. Deploy it.**  
> *From Project Idea to Working Prototype.*

HA Labs is an engineering project platform founded by **Harish and Ajithkumar** to help engineering students go through the complete real-world engineering lifecycle:
**Idea → Plan → Build → Test → Deploy → Document → Present**

## 🚀 Key Features

1. **Brand Identity & Monogram**: Custom geometric H+A circuit monogram, dark navy/black base (`#060913`), electric cyan/blue (`#00d2ff`/`#38bdf8`) & violet accents.
2. **Interactive Real-Time Pipeline**: Visual node graph connecting `IDEA → PROJECT → HARDWARE → CODE → CLOUD → DEPLOY → DOCS → VIVA`.
3. **Project Recommendation Engine**: Multi-dimensional filtering by Branch (ECE, EEE, CSE, IT, AI & DS, Mechanical), Budget, Technology, and Hardware with weighted match scoring.
4. **Interactive Modular Builder**: "Your Project, Your Way" customizer to adapt hardware sensors, cloud backends, and UI frameworks with dynamic cost/timeline recalculation.
5. **Engineering AI Copilot**: Specialized assistant for hardware pinout troubleshooting, ESP32 debugging, and viva exam defense preparation.
6. **20+ Production Projects**: Realistic engineering projects with Bill of Materials (BOM), system dataflows, source code templates, and viva Q&As.
7. **Student SaaS Workspace**: Milestone tracking (75% build progress), package asset downloads, and support ticketing.
8. **Institutional College Portal**: Faculty supervisor dashboard for batch reviews and anti-plagiarism verification.
9. **Admin Panel**: Operational KPI cards, project publisher, and build request manager.
10. **DevOps Ready**: Healthcheck endpoints (`/health` & `/api/health`), multi-stage Dockerfile, docker-compose, and GitHub Actions CI.

## 💻 Local Development

```bash
# 1. Install dependencies
npm install

# 2. Run the local development server
npm run dev

# 3. Open browser at:
http://localhost:3000
```

### Production Build & Containerization

```bash
# Build production bundle
npm run build

# Or launch with Docker
docker-compose up --build -d
```
